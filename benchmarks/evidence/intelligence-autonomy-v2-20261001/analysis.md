# v2 分析与局限

## 能确认的事实

终止决定改为诊断接受后的独占批次，没有放宽执行门禁、场景或预算。配置不匹配与实际 cgroup OOM 两项 CLAWKIT 样本提交有效诊断并交接，未派发修复。其他模型组中的正确诊断和错误处置分别保留。SYSTEM 兜底一律不计模型诊断或选择成功。

源码在 fad996bdb6fa56df841f399525c4e8e49f09dce6 冻结，2231 个输入文件逐项匹配源码 ZIP；40 项完整、单一参数及工具集合、实际用量与独立业务审计通过，清理后本次项目无容器残余。两次派发均来自强规则，只操作登记容器，不操作依赖。

## 外部失败

原始 Run Recorder 的 provider_call_completed 记录确认 21 次 HTTP 402：Insufficient Balance。外部失败按顺序发生，CLAWKIT 与普通 Agent 各六项，无知识组九项。它们不表示模型“不会诊断”，也不能当零费用；缺少 usage 单列。

原始生成的 MODEL_OR_PROTOCOL_FAILURE 是失败汇总类别，包含这些供应商失败。新增 external-failures.json 从原事件提取已确认原因，不改变原始实例、标签或分数。只筛选余额耗尽前的成功项做比较会改变样本分母，本报告不这样处理。

## 尚未解决的诊断成本

CLAWKIT 的历史错误/当前健康和过期来源样本仍在固定 30000 Token 决定预算下停止。预算停止是已知失败路径，不是自主恢复；终止工具协议修正没有自动解决上下文成本。继续调查成本必须包含采证、知识、诊断、最终决定及全部失败轮次。

普通 Agent 的服务退出样本诊断为应用故障，却选择交接；截断与缺失来源选择继续调查，未达到本次预设的交接结果，三项记 FAIL。评分限定单次决定；它不测完整十分钟持续会话在后续补证周期中的收益。包内连续会话另以已有开发夹具验证，不与正式分数拼接。

## 不能声称的收益

- 不能根据本轮的组间差异证明知识有效、无效或 Agent 优于强规则。
- 受控 REVIEWED 状态不是实际团队审阅，历史/案例命中不是现场根因确认。
- v2 沿用 v1 场景，不是新的独立留出集；每实例一次，不是稳定性试验。
- 六对关系是固定拓扑与时间窗合同，不是共同根因推断或真实 Alertmanager 部署验收。
- 没有生产 MTTR、真实用户规模、人工时间基线或实际扣费数据。

补充额度后应整轮重开、再次冻结和独立审计，保留本轮及全部开发失败；不补跑替换、不宣称已验证知识收益。
