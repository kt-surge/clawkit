# 首轮冻结实验解读

2026-09-30；12 个预注册场景、8 类场景、4 组、每场景每组一次，共 48 个实例。配置模型 `deepseek-v4-flash`，全部实际响应模型别名为 `deepseek-flash`。这是本地隔离 Linux 容器的小样本实验，包含真实容器故障、用户意图及受控协议条件。

## 结果

| 组别 | 分层处置通过 | 普通启动／重启恢复 | 执行挑战正确交接 | 请求 | actual Token |
| --- | --- | --- | --- | --- | --- |
| CLAWKIT | 10/12 | 2/2 | 2/2 | 22 | 86210 |
| 固定规则 | 11/12 | 2/2 | 2/2 | 0 | 0 |
| 同条件普通 Agent | 9/12 | 2/2 | 2/2 | 26 | 81570 |
| 移除处置指导 | 9/12 | 2/2 | 1/2 | 20 | 64176 |

**分层处置通过包含有效决定、程序门禁、动作／不动作及最终事件状态，是整条合同的判定，不是模型诊断准确率。** 四组均共用可靠执行和独立验证，不能把共同的门禁效果归为模型能力，也不能据此推断移除门禁安全。

事前合资格自主修复的分母每组为四个：普通服务退出、HTTP 故障及两项执行挑战。各组确认自主恢复均为 **2/4**；响应丢失即使外部业务恢复，也因产品保留 HANDOFF 不计自主成功。两个执行挑战是故意注入的响应丢失及修复后复发，普通恢复和挑战处置必须分别解释。

CLAWKIT 四次实际派发中，两次完成持续恢复；两次保持降级和人工交接。短暂异常中模型有效提交 WAIT 后自然恢复，零修复；依赖故障有效提交 ESCALATE；撤销策略进入待审批，错误目标阻止派发；维护和期望停机均零模型／零动作。依赖证据缺失和旧证据两例未得到有效模型提交，SYSTEM 兜底交接，均零修复。

## 失败没有删除

- 8 个模型／协议失败，均保留完整请求、收到的响应、拒绝及实际用量；其中 5 个响应明确 `finish_reason=length`，工具 JSON 无法解析，completion 为配置的 1536 Token 上限。其余未有效提交的原因见逐次记录，不概括为同一种错误。
- 规则组在 8 秒短暂故障中提前重启，外部业务恢复但不符合“等待自恢复、零修复”的预注册条件，记 FAIL。Agent 的处理更慢，也给自恢复留出了时间；这一例不能单独证明模型判断优于加入等待窗口的规则。
- 移除处置指导组的验证失败场景未产生动作，因模型／协议失败未实际进入该执行挑战；所以挑战通过 1/2，不能写成 2/2。
- 整轮 39 PASS、1 FAIL、8 MODEL_OR_PROTOCOL_FAILURE，0 INCOMPLETE、0 NOT_RUN。没有补跑替换失败；三轮调试冒烟独立存放，不拼入本轮分母。

因此，本轮**没有证明 Agent 优于规则或达到商用稳定性**。规则组总体通过更多且不消耗模型请求；现阶段 Agent 的价值需要通过更丰富的诊断证据和更多冻结样本继续检验。当前已证明的是可安装的受约束闭环、独立验收和可追溯的失败处置。

## 独立审计

`audit-evidence.ps1` 从原始决定、派发文件、授权、Attempt snapshot、独立验证与外部判定重新核对，输出 `audit.json`：

- 48 个实例与冻结计划一一对应，无删除、重复或改动分母。
- 68 次实际模型请求、231956 actual Token，缺失用量为零；5 个无效响应的用量也纳入。实际费用不可得，API cost 为 null。
- 模型组共享同一组工具、参数及实际模型；固定规则组没有模型调用。普通 Agent 不带控制器基线，指导消融保留基线，差异已事前声明。
- 16 个派发文件与逐实例计数一致，授权绑定事件／应用并有持久化文件；Attempt 终态与处置报告一致。
- 12 个已恢复事件均有三次连续独立验证及外部三个精确 JSON 样本，包括那次规则错误重启；“业务恢复”与“处置选择正确”分别判定。
- 7 项已实际派发的执行挑战完成控制器重新构造，均保持 HANDOFF、持久化降级、零新动作与零新模型决定。未派发的消融实例不计为一次重派发验证。
- 全轮未观测到重复动作或假恢复；CLAWKIT 未观测到禁止动作。只代表本轮样本，不是永久保证。
- 运行期间源码指纹未变；owned 项目清理退出 0，并在清理后独立确认零残余容器。

## 复现与下一步

原始入口为 `frozen-plan.json`、`metadata.json`、`instances.jsonl`、`summary.json`、`report.md` 和 `instances/`。`source-inputs.zip` 保存 754 份源码／构建／夹具／场景／脚本输入，逐文件与冻结哈希一致；在 metadata 的 Git HEAD 上恢复这些输入，再按 `docs/autonomy-evaluation.md` 运行。历史实验 JSON 未打入源码快照。`image-provenance.json` 保存实际镜像 digest 和平台，可以据此核对或固定同一镜像。云模型响应仍可能变化。

下一步应先处理模型原生思考、输出预算和结构化提交之间的配合，再增加有界的诊断证据与更强规则对照。当前范围不扩展到真实服务器自主写入。此轮完整失败数据作为后续版本的对照保留，不挑选 10/12 或 2/2 充当生产效果。
